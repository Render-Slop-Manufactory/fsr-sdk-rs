Updated: 2026-10-30. **Common rc1 pair qualified on Windows (1,448/1,448), Deck (16/16 + 17/17) and Machine (12/12); final P08 reconciliation accepted; publication simulation passes with exact rc1 hashes and both uploads aborted; temporary archives removed and top-level README approved; documentation/link review complete; unpublished.**

upscaling access to the pinned SDK v2.3.0 on the supported Windows x64/MSVC + DX12
target. This supersedes the earlier M10-only selection with optional additions.
The selected interfaces are now implemented and verified within their recorded
source/provider bounds; rc1 package/host qualification now passes, with remaining
release gates tracked below. Keep implemented changes in
[CHANGELOG.md](../../CHANGELOG.md) and track remaining work in the roadmap.
This document tracks preparation, not a completed release check.

and future-candidate guidance. The linked rc1 reports record the completed
qualification; this documentation synthesis requires no additional full run.

checks during development and batch full qualification on the finished candidate.
The `release` composition already includes the source, MSRV and infrastructure
checks; separate `ci`/`msrv` runs are not mandatory prerequisites to it.

distribute those exact files to every host. Select them explicitly rather than
independently packaging a different pair per host. The rc1 distribution directory
has been removed after qualification; its
[preparation inventory](2026-10-29-candidate-package-preparation.json) retains the

```sh
python tools/verification/run.py run release --require-passed --native \

  --sys-archive /path/to/fsr-sdk-sys-0.1.2.crate
```
