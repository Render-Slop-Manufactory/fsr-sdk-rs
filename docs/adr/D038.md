# D038 — Typed BGRA and sRGB colour resources

- Date: 2026-10-24.
- Status: **accepted** under the maintainer's instruction to formulate, implement
  and verify the BGRA/sRGB contract. Implementation and evidence checkpoints are
  separate below.
- Scope: U05, development wrapper `0.3.0` / sys `0.1.2`, SDK v2.3.0, Windows
  x64/MSVC + DX12, both public ownership families and shared optional preflight.

## Accepted allocation and role matrix

Extend D035's main colour, main output and both reactive-generation colour-input
roles with exactly three typed allocations. Other roles keep their existing
formats. Generation output remains R8_UNORM; typeless colour allocations are
not admitted. Select from actual `GetDesc`, without a public format/view override.

| Allocation | Native surface value | Backend SRV | Backend UAV if allocation permits it |
|---|---|---|---|
| B8G8R8A8_UNORM | B8G8R8A8_UNORM (14) | B8G8R8A8_UNORM | B8G8R8A8_UNORM |
| R8G8B8A8_UNORM_SRGB | R8G8B8A8_SRGB (12) | R8G8B8A8_UNORM_SRGB | R8G8B8A8_UNORM |
| B8G8R8A8_UNORM_SRGB | B8G8R8A8_SRGB (15) | B8G8R8A8_UNORM_SRGB | B8G8R8A8_UNORM |

Preserve exact native metadata, real usage flags and resource states. Bind the
three surface constants with independent Rust/pinned-header C++ assertions;
layouts and dependencies do not change. Both generation inputs may independently
select an admitted format, with renderer-established comparable signals.

## Device inspection and failure contract

Keep existing geometry, canonical resource/device membership, aliasing, lifetime
and terminal native-failure rules. Metadata and membership reject before device
format queries. Preserve the shared fixed role order and repeat queries during
recording even after optional preflight. Add no cache or implicit GPU operation.

For BGRA UNORM use D035's typed-format profile: TEXTURE2D and SHADER_LOAD for
all admitted roles, SHADER_SAMPLE for inputs, TYPED_UNORDERED_ACCESS_VIEW when
the real allocation allows a UAV, and UAV_TYPED_STORE for main output. BGRA
typed UAV/store support is device-conditional; absence rejects the supplied role.

For typed sRGB inspect the exact views separately:

1. If the allocation permits UAV access, require OPTIONS3's
   `CastingFullyTypedFormatSupported` before view queries, including for an input
   that the operation reads only. The backend also creates its UNORM UAV.
2. Query the actual sRGB SRV format for TEXTURE2D + SHADER_LOAD, and additionally
   SHADER_SAMPLE for inputs. Do not ask for an sRGB UAV.
3. If UAV-capable, query the matching UNORM format for TEXTURE2D +
   TYPED_UNORDERED_ACCESS_VIEW. Main output additionally requires UAV_TYPED_STORE;
   read-only inputs acquire no typed load/store requirement. No UAV_TYPED_LOAD
   requirement is introduced. Read-only sRGB allocations need no casting query.

Outputs require ALLOW_UNORDERED_ACCESS and remain shader-readable because the
backend creates an SRV. Missing view/casting support reports the resource role
with `ResourceProperty::FormatSupport`. Query failures preserve exact HRESULT,
`ContextDeviceForResource(role)` and `CheckFormatSupport` / `CheckFormatCasting`.
Inspection failures make no native call, leave the context usable and allow retry.
Existing formats, query behaviour and D034 RG32F diagnostics remain unchanged.

## Signal and ownership boundaries

DXGI BGRA views expose logical RGB; the wrapper performs no software swizzle.
sRGB SRVs decode RGB while reading; alpha is not sRGB-decoded. UNORM UAV stores
do not automatically sRGB-encode merely because the allocation is named sRGB.
This describes view operations, not the internal signal processing of every
provider or an output/presentation colour policy.

Keep D027 creation classification, dispatch hints, checked pairing and explicit
per-frame exception unchanged and independent of format. Do not infer or rewrite
them from the allocation. The renderer establishes the actual provider-facing
signal, primaries, alpha convention and any conversion/presentation stage.
No conversion, copy, fallback, provider allow-list or history-reset policy is added.
Actual-provider support, transitions, command submission, synchronization and GPU
lifetimes remain explicit obligations at the existing unsafe native boundary.
Device support and passing executions are not universal provider certificates.

## Basis and verification scope

The [source audit](../research/records/2026-10-24-src-bgra-srgb-audit.md) corrects
the incoming source citations and confirms exact helper/backend mappings.
[T1/T2](../research/records/2026-10-24-exp-bgra-srgb-views.md) execute independent
DX12 views/stores. [T3/T4](../research/records/2026-10-24-exp-bgra-srgb-sdk-integration.md)
record actual direct SDK calls on selected 4.1.1/3.1.5 and generation on 3.1.5.
These are prerequisites to wrapper implementation, not public-wrapper evidence.

Verify the role matrix and exact descriptor mapping; separate SRV/UAV capability
and casting failures; same-HRESULT role attribution; fixed query order; retry;
preflight/recording agreement; native entry suppression; COM reference balance;
poison precedence and native failure. Run stable/MSRV/ABI/public consumers and
both public families against the pinned runtime with fenced output/mask writes
and explicit cleanup. UAV-capable inputs require their own bounded cases.

No reconstructed-image equality, numerical quality tolerance, sharpening effect,
CPU mask-algorithm comparison or provider-quality campaign is part of acceptance.
The earlier out-of-scope numerical failure remains historical and selects no
further quality work. Final release archives and remaining U05 families remain
separate.

## Checkpoint

Implemented for both public families and their shared preflight/recording paths.
[Verification](../release/2026-10-24-bgra-srgb-verification.md) passes 182 current
CI, 159 exact-MSRV and 102 public native stages, including 92 isolated workloads
on selected 3.1.5/4.1.1 and generation on 3.1.5. Exact mapping, error paths,
UAV-capable inputs, writes, fences and cleanup pass without image/algorithm
comparisons. Other U05 candidates and final release archives remain separate.
