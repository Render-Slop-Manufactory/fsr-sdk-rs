# D002 — Pin AMD FSR SDK v2.3.0 as the initial native baseline

- Recorded: 2026-09-16
- Status: accepted — explicitly selected by the maintainer

**Choice:** AMD FSR SDK `v2.3.0` is the initial pinned native SDK baseline.
Use this concrete release, not `main` or an implicit latest release. Compatibility
with later SDK releases is not assumed; upgrades require an explicit decision
update and appropriate compatibility verification. Rust crate versions remain
independent of AMD SDK and individual technology/runtime versions.

**Rationale:** A concrete upstream release gives native implementation and
investigation a reproducible reference rather than a moving target. This version
selection is accepted project policy, not a question for Milestone 1 research.

**Upstream metadata:** Verified on 2026-09-16 against AMD/GPUOpen's official
repository, `GPUOpen-LibrariesAndSDKs/FidelityFX-SDK`:

- Release title: **FSR SDK v2.3.0**; tag: `v2.3.0`.
- Release: [official release page](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK/releases/tag/v2.3.0).
- Tagged commit: [`60f4ea81909200d8542eca14dccb2628b763a9a3`](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK/commit/60f4ea81909200d8542eca14dccb2628b763a9a3).

**Consequences and limits:** Remaining Milestone 1 work examines this baseline's
required headers, ABI and safety contracts, runtime artefacts, applicable terms,
binding strategy, and initial runtime discovery path. This decision does not
establish runtime compatibility, select an acquisition mechanism, or record
verified binary checksums. No SDK/API investigation or implementation is completed
by recording the version choice.
