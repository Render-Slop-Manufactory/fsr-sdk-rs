# D039 — Remaining external upscaling format access

- Date: 2026-10-24.
- Status: **accepted** under the maintainer's instruction to continue and finish
  the remaining U05 access, implement it and verify it. Verification is a
  separate checkpoint below.
- Baseline: D034/D035/D037/D038, SDK v2.3.0, Windows x64/MSVC + DX12,
  development wrapper 0.3.0 / sys 0.1.2, both ownership families.
- Basis: [complete remaining-format accounting](../research/records/2026-10-24-src-remaining-upscaling-formats.md).

## Contract

Accept the exact allocation/role/view matrix in that source record. Existing
typed routes retain their contracts. No public format selector, unchecked
override, new resource owner, hidden copy or signal conversion is introduced.
Immutable `GetDesc` metadata selects the fixed view; native metadata preserves
the public helper's enum and usage, except the documented RGB32F helper gap.

Expose all 40 pinned surface-enum constants in the raw crate, independently
asserting their values in Rust and MSVC. Generic raw representation does not
imply acceptance in a public upscaling role.

For RGB32F typed/typeless colour, set the existing native RGB32F enum (5), whose
reverse backend mapping exists despite the missing public helper cases.
Accept main colour and each generator colour input; reject output and UAV-capable
allocations. Require `TEXTURE2D | SHADER_LOAD`, without inventing filtering
capability. The caller must establish that the selected provider/operation uses
this load-only representation. No provider allow-list or automatic fallback.

For other new ordinary/typeless routes, query the actual fixed typed view for
`TEXTURE2D | SHADER_LOAD`, plus `SHADER_SAMPLE` for inputs. UAV-capable inputs
require a legal typed UAV view without typed shader load/store requirements.
Outputs require the typed UAV view and `UAV_TYPED_STORE`; no typed loads.
Shared-exponent/BGRA output remains device-conditional. Missing bits reject
before native entry, preserving a usable context.

Add typed D16 and typed/typeless D24 depth-buffer routes, with no UAV or shader-
read denial. Query the DSV for texture/depth support and the exact depth-plane
SRV for texture/load/sample support. Typed allocations additionally require
OPTIONS3 fully typed casting. Preserve the helper's D24 integer enum without
using an integer SRV. As in D037, callers transition the whole depth/stencil
resource and own DSV production, both planes, synchronization and completion.

R32 typeless without a depth flag is an ordinary R32F view for depth/exposure;
with the flag, its depth role retains D037's D32 profile. R16 typeless is R16F
only and rejects depth/stencil capability; it cannot expose D16 UNORM production.
Typed R16 UNORM provides normalized scalar depth. Typeless R8 supplies the same
documented mask representation and is accepted in supplied/generated mask roles.
Typeless colour defaults to FLOAT/UNORM, never a caller-selected sRGB view.

Keep view queries after metadata and canonical device membership. Existing
colour/depth/motion/output query order remains, followed by new exposure and
supplied-mask queries. Generator checks retain their role order. Failed queries
preserve role, operation and exact HRESULT. Optional validation and recording
share inspection, repeated at recording. Native errors retain terminal policy.

The source record partitions every pinned surface value and D035 residual row.
Integer shader resources, alternative mask/exposure encodings, normalized/
integer motion, stencil/view-only allocations and arbitrary view overrides are
outside this documented upscaling contract. This is not a claim that a special
provider can never consume any such resource. No applicable gap is deferred by
calling all generic converter entries unsupported.

## Verification

Controlled tests cover role mappings, all required bits, exact query failures,
view-specific queries, typed casting, flags, metadata/device precedence, retry,
native non-entry, terminal errors and reference balance for both owners.
Native checks vary each new role independently, preserve uploaded inputs, check
allocation/helper parity (explicit RGB32 exception), fenced writes, selected
provider, ordinary debug/device diagnostics and explicit cleanup. Generation
colour and output are independent checks on selected 3.1.5; main dispatch also
selects 4.1.1. Depth checks include actual DSV production, independent shader
depth and copied planes. No FSR-output equality, reconstruction tolerance,
sharpening-effect or mask-algorithm prediction is an acceptance condition.

Use [the frozen protocol](../../tools/verification/resource-formats-protocol.md)
and record stable/MSRV/ABI/consumer and actual public GPU outcomes before
closing U05. Final release archives and other upscaling work remain separate.

## Checkpoint

Implemented for both public owners and [verified](../release/2026-10-24-resource-formats-verification.md):
182 stable CI, 159 exact Rust 1.88.0/MSRV and 280 native stages pass with
unchanged inputs within each accepted run. All 270 public contexts complete
810 fenced frames, 798 main calls and 198 generator calls. Earlier disk-full
attempts remain failed and documented; successful transient payloads now have
bounded retention. Together with D034/D035/D037/D038 and the complete source
accounting, this closes U05 for bounded SDK access. Final release archives and
R03/U04 remain separate.
