# Compact temporal metric diagnosis evidence

Evidence for the [experiment record](../2026-10-11-exp-temporal-quality-metric-diagnosis.md).
The fixed protocol and independent native executions address contrary quality
rankings, not V01 acceptance or a new public API contract.

- `measurements.json`: pooled native measurements for every arm/repeat, exact
  repeat identity, input audit and synthetic metric counterexamples.
- `protocol.json`, `arms.txt`, `jitter.txt`: the frozen inputs and execution matrix.
- `inputs.json`: tested source/SDK file hashes and combined identity.
- `outcomes.json`: successful attempt's 19 case outcomes, commands, native
  equipment/artefact identities and compact payload inventory digests.
- `attempts.json`: all four attempts, including pre-dispatch script/permission/
  input failures and the incomplete sandbox attempt's four recorded outcomes.
- `native-observations.json`: independent log/metadata counts, completion checks,
  payload totals and actually loaded module identities.
- `checks.json`: relevant ordinary checks and local package-content inspection.
- `retention.json`: validated temporary-diagnostic removal count, size and
  inventory digest; original structural outcome is preserved.
- `contact-sheet.png`: frame 40, a fixed 128×72 display-pixel crop along the
  trailing silhouette, enlarged 2× with nearest sampling. Rows are flat slow,
  flat fast and textured slow; columns are correct, reverse, zero motion,
  negated jitter and reset every frame. Linear RGB is clipped for PNG display
  only; measurements remain unclipped. This is not a perceptual evaluation.
- `artifacts.json`: hashes/sizes of the permanent supporting files.

Full generated GPU images/inputs, verbose analyses, build products and AMD
binaries are excluded. The temporary local diagnostics were compacted after
their integrity and measurements were checked. Exact old images cannot be
reconstructed from hashes. Reproduction needs the existing trusted SDK and
equipment; a new run is not guaranteed to reproduce old GPU bytes. Case log
paths identify local attempt artefacts and do not claim those full logs are
included here. The main record contains the observations and reconstruction
limits without requiring unpublished history.
