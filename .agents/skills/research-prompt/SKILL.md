# Research Prompt

Read [shared research guidance](../RESEARCH.md), relevant project context, and
existing topic findings. Determine the narrow question and what is already
known. Ask only if ambiguity would materially change the investigation.

Produce a copy-ready brief assuming the researcher cannot access this repository.
Include the project purpose, relevant crate and platform boundaries, implemented
state, known findings with version limits, and precise unanswered questions.
Supply the necessary context inline rather than bare local file references.

Separate questions answerable from sources from those needing Windows, an AMD
runtime, licensed materials, or GPU experiments. Include only relevant licensing,
ABI, ownership, loading, or distribution concerns.

Embed the applicable evidence and source-record requirements from the shared
guidance. Request one self-contained Markdown record, including differences from
the baseline and unresolved questions. Do not imply research accepts a design.

Return the finished prompt. Do not conduct the investigation, edit repository
files, or dispatch it to another agent unless the user also requests that work.
