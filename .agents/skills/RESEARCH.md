# Shared Research Guidance

For research prompts, investigations, experiments, records, and synthesis, read
[the research process](../../docs/research/PROCESS.md). It owns the shared
evidence standards, record conventions, and integration workflow.

Use [the research index](../../docs/research/README.md) to find current topic
coverage. Read only the relevant topic and historical evidence needed for the
question. Skill-specific execution steps remain in each SKILL.md.

Use [research-investigation](research-investigation/SKILL.md) to gather and
analyse source evidence, and [research-experiment](research-experiment/SKILL.md)
to run a bounded probe and capture its execution evidence. Both finish through
[research-record](research-record/SKILL.md), which also handles an explicit
request to write up existing findings. Final report assembly belongs there;
capture provenance and observations while investigating or executing, not only
at the reporting step.

Recording is the normal completion of a requested research workflow. Respect
the user's output constraints: read-only or response-only work produces a report
in the response; otherwise save the record within the authorized repository
scope. A skill does not grant additional execution or filesystem permissions.
Ordinary implementation, code review, lookups, and routine checks do not
automatically invoke this workflow.

Use [research-prompt](research-prompt/SKILL.md) only to prepare an external brief,
and [research-synthesis](research-synthesis/SKILL.md) to integrate completed
records when requested. A completed record alone does not authorize synthesis.
